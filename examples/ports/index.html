About Ports

This example demonstrates connection points (ports) on nodes.

  • Input nodes have input ports on the left
  • Process nodes have both input and output ports
  • Output nodes have output ports on the right
  • Drag from an output port to an input port to connect
  • Connections snap to the nearest port
  • Editable polyline: select edge, drag blue points, click + to add more points
  • Attach to Outline: when ON, edges attach anywhere on shape contour; Shift+click on node to start connection
  • Double-click any node or edge label to edit it inline
