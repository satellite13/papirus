Composite Nodes

Composite nodes contain a tree of child components laid out with a flexbox-like engine.

  • BPMN Task — icon + name + markers
  • ArchiMate — icon in corner + centered name
  • C4 Container — multi-line styled text
  • UML Class — sections with dividers
  • Swimlane — vertical rotated text
  • Status Card — colored indicator bars

Edge labels demo `labelPosition` + `labelFollowPath` + `labelLineGap`.

Component schema supports editor fields like `label`, `bindToProperty`, `bindsNotationIcon`.

Double-click a node to edit its name. Click icons to trigger callbacks.

Keyboard Shortcuts

  • Delete Remove selected
  • Ctrl+Z Undo
