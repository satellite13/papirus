Custom Shapes

Create custom node shapes using Path2D. Add svgPath for correct SVG export.

  • Chamfered Rect — Beveled corners
  • Hexagon — 6-sided polygon
  • Cylinder — Database shape
  • Document — Page with fold
  • Outline — Attach edges anywhere on shape contour
  • Double-click a shape or connector to rename label inline
Shape Properties

Select a shape to see its properties

Code Example
const node = new CustomShapeNode({
  x: 100, y: 100,
  width: 140, height: 80,
  path: createPath,      // Path2D for canvas
  svgPath: createSvgPath, // SVG path for export
  labelPlacement: 'center',
});
