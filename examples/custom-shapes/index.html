Custom Shapes

Create custom node shapes using Path2D.

  • Chamfered Rect — Beveled corners
  • Hexagon — 6-sided polygon
  • Cylinder — Database shape
  • Document — Page with fold
Shape Properties

Select a shape to see its properties

Code Example
const path = new Path2D();
path.moveTo(10, 0);
path.lineTo(w - 10, 0);
path.quadraticCurveTo(w, 0, w, 10);
// ... more path commands

const node = new CustomShapeNode({
  x: 100, y: 100,
  width: 140, height: 80,
  path: () => path,
});
